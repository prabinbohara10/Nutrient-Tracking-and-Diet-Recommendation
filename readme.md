## Nutrient Tracking and Diet Recommendation

The system aims to track the various parameters of an user/patient, give what the perfect diet plan would be and recommend the appropriate food. This helps an user to follow healthy dietary routine and so as to become fit keep well track of factors like BMI, blood pressure, sugar level etc.

It consists of two modules:
- Diet Type prediction
- Food recommendation based on the predicted diet type

Various features or parameters being tracked are:
- Patient Demographics – Age, gender, height, weight, and BMI.
- Medical History – blood pressure, cholesterol, blood sugar level
- Lifestyle Data – Daily steps, alcohol and smoking habits.
